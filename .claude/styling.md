# Claude AI Prompt — Tradie Job Manager Custom UI/Wireframe Style

You are a senior SaaS UI/UX designer and product designer.  
Design a unique, premium, non-generic UI system for **Tradie Job Manager**.

## Product
**Tradie Job Manager** is a SaaS + mobile app for tradie/service businesses such as plumbers, electricians, cleaners, HVAC, handyman, carpenters, painters, pest control, and field-service teams.

The app includes:
- Owner web dashboard
- Employee mobile app
- Customer portal
- Job scheduling
- Quotes
- Invoices
- Payroll
- WorkSafe compliance
- Tax/BAS reports
- Notifications
- Subscription billing

---

# Design Direction

Do **not** create a generic AI SaaS dashboard.

Use a custom visual identity inspired by:

## Icons
Use **Iconsax** style icons from:
https://app.iconsax.io/

Icon style:
- Linear / outline icons
- Rounded edges
- Clean professional SaaS look
- Consistent stroke width
- Use icons for every major module

## Motion / Interaction Inspiration
Use motion design inspiration from:
https://www.designspells.com/

Motion style:
- Smooth micro-interactions
- Hover lift effects
- Card reveal animations
- Soft transitions
- Interactive dashboard widgets
- Animated progress indicators
- Sliding panels
- Stepper animations
- Route/map transition effects

## Shape / Pattern Direction
Use unique background patterns and shapes:
- Soft abstract blobs
- Rounded geometric cards
- Subtle grid patterns
- Flowing route-line patterns
- Map-path inspired curves
- Invoice/document paper-stack shapes
- Safety shield shapes
- Worker/job status pill shapes
- Layered glass-style panels

Avoid boring rectangular layouts only.
