# 2. User Registration Module — Full Details

## Main Purpose

The **User Registration Module** creates verified accounts for:

1. **Business Owner**
2. **Admin / Employee / Worker**
3. **Accountant**
4. **Customer portal user** later

It must ensure every user is linked to the correct **business account**, role, permissions, tax/reporting setup, and security controls.

---

# What We Will Implement

## 1. Business Owner Registration

The owner creates the main business account.

### Required Owner Details

* Full legal name
* Email
* Mobile number
* Password or passkey setup
* Terms and privacy acceptance

### Required Business Details

* Legal business name
* Trading name
* ABN
* ACN, if company
* Business structure
* Industry/trade type
* GST registration status
* GST registration date, if registered
* Business email
* Business phone
* Registered business address
* Trading/service address
* Postal address
* Financial year start/end
* BAS reporting cycle
* Accounting method: cash/accrual
* Default GST rate
* Invoice prefix
* Payment terms
* Bank account name
* BSB
* Account number
* Payroll contact person
* PAYG withholding status
* Default superannuation rate
* WorkSafe/state registration number, if applicable
* Public liability insurance provider
* Policy number
* Insurance expiry date

---

# 2. Employee / Worker Registration

Employees must **not create a separate business account**.

They register through invitation only.

### Flow

```txt
Owner/Admin invites employee
→ employee receives invite link
→ employee accepts invite
→ employee creates login
→ employee completes required profile
→ system links employee to same business_id
→ role and permissions are applied
```

### Required Employee Details

* Full legal name
* Preferred name
* Email
* Mobile number
* Home address
* Emergency contact name
* Emergency contact phone
* Role: worker, supervisor, admin, accountant
* Employment type: full-time, part-time, casual, contractor
* Job title/trade type
* Start date
* Hourly rate or salary
* Pay cycle
* Bank account name
* BSB
* Account number
* Super fund name
* Super fund USI
* Super member number
* Tax File Number, securely stored
* White Card number, if required
* Trade licence number, if required
* Licence expiry date
* Safety induction status

---

# 3. Accountant Registration

Accountant access should be invite-only.

### Accountant Can Access

* bills
* invoices
* tax reports
* BAS/GST reports
* payroll reports, if allowed
* export reports

### Accountant Cannot Access By Default

* job route tracking
* worker private notes
* customer messages
* admin settings
* passkey/session settings

---

# 4. Customer Registration Later

Customers should only register through:

```txt
quote link
invoice link
booking link
```

Customer access is limited to:

```txt
their own quotes
their own invoices
their own bookings
their own messages
```

---

# Registration Rules

## Owner Account Rule

```txt
Owner account becomes active only after:
1. Email is verified
2. Required business details are completed
3. Terms/privacy are accepted
```

## Employee Account Rule

```txt
Employee account becomes active only after:
1. Invite token is valid
2. Email matches invited email
3. Required employee profile is completed
4. Role is assigned
```

## Tenant Rule

Every user must belong to one `business_id`.

```txt
users.business_id = businesses.id
```

No user should access another business’s data.

# Validation Rules

## Business Validation

```txt
ABN must be 11 digits
ACN required if business structure = company
GST date required if GST registered = yes
BSB must be 6 digits
Default GST rate required
BAS cycle required
Accounting method required
Business address required
Insurance expiry required if insurance provider is entered
```

## Employee Validation

```txt
Email must match invite email
TFN stored encrypted
Bank details stored encrypted
Hourly rate required for casual/part-time
Salary required for full-time salary worker
White Card required for trade roles where applicable
Emergency contact required
```

---

# Zero Trust Checks

Every registration action checks:

```txt
Is the token valid?
Is the token expired?
Has the token already been used?
Does invite belong to correct business_id?
Is this role allowed?
Is this user allowed to invite others?
Does email match invited email?
Are required details completed?
```
