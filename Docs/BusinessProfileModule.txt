# 8. Business Profile Module — Full & Final

## Main Purpose

The **Business Profile Module** stores the official business identity, tax details, invoice details, payroll settings, compliance information, and contact data for each tradie business.

It supports:

```txt
tax reports
BAS/GST reports
invoices
quotes
payslips
WorkSafe records
accountant exports
customer-facing documents
subscription/business verification
```

Core rule:

```txt
Each business profile belongs to exactly one business_id.
Only Owner can create/update business profile details.
Employees can view limited business information only if needed.
```

# Access Control

## Owner

Can:

```txt

```

## Employee

Can view only limited business information:


# Validation Rules

## Business Identity

```txt
Legal business name required
Trading name required
ABN required
ABN must be 11 digits
ACN required if business_structure = Company
ACN must be 9 digits if provided
Business structure required
Industry type required
```

## Contact

```txt
Business email required and valid
Business phone required
Support email valid if provided
Website valid if provided
```

## Address

```txt
Registered address required
Service address required
Postal address required
State required
Postcode required
Country required
```

## Tax

```txt
GST registered required
GST registration date required if GST registered = true
Default GST rate required
If GST registered = true, default GST rate usually 10
If GST registered = false, default GST rate should be 0
BAS cycle required

Financial year dates required
```



# Security Techniques

Implement:

```txt
Owner-only update access
tenant isolation using business_id
PostgreSQL RLS
field-level encryption for bank details
signed URLs for logo/compliance documents
input validation
audit logs for all profile updates
soft delete
rate limiting on update endpoints
```

Never expose:

```txt
raw bank account encryption values
another business profile
internal storage paths
deleted records by default
```

---

# Zero Trust Rules

Every request must check:

```txt
Is user authenticated?
Is user part of this business_id?
Is user Owner for sensitive updates?
Is subscription active/trialing?
Does requested profile belong to current_user.business_id?
Is the field allowed for this role?
Should this action be audited?
```

# Business Profile Completion Logic

The business account is not fully active until required sections are complete.

Required completion checklist:

```txt
legal profile completed
contact details completed
address completed
tax settings completed
invoice settings completed
payment details completed
payroll settings completed, if payroll enabled
compliance details completed
terms/privacy accepted
email verified
```

Example response:

```json
{
  "profile_complete": false,
  "missing_sections": [
    "tax_settings",
    "payment_details",
    "compliance_details"
  ]
}
```
